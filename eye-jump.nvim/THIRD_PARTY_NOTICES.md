# Third-party code

`vendor/tobiifree/` contains
[Aetherall/tobiifree](https://github.com/Aetherall/tobiifree) at commit
`88285ec845a2c8a7c9ac1b303e573d2d0505a987`. It includes the Zig source,
TypeScript SDK, generated WASM bundle, and GPL-3.0 license.

The fullscreen calibration helper uses `@kmamal/sdl` (MIT) and SDL (zlib).
